# タイプ画像の置き場所

このフォルダに各タイプの画像を置くと、結果ページで絵文字の代わりに表示されます。
**画像が無くても動きます**（自動で絵文字プレースホルダーが表示されます）。

## ファイル名のルール

`<MBTIコード>.png` という名前で配置してください（推奨: 正方形 512×512 以上）。

| タイプ | ファイル名 |
| --- | --- |
| 🌘 影の皇帝 | `INTJ.png` |
| 👁 観測者 | `INTP.png` |
| 👑 支配者 | `ENTJ.png` |
| 🕷 黒幕 | `ENTP.png` |
| ⏳ 終焉の預言者 | `INFJ.png` |
| 🌑 虚無主義者 | `INFP.png` |
| 🕯 狂信者 | `ENFJ.png` |
| 🌹 誘惑者 | `ENFP.png` |
| ❄ 氷結者 | `ISTJ.png` |
| ⚔ 堕ちた勇者 | `ISFJ.png` |
| ☠ 審判者 | `ESTJ.png` |
| 🎭 偽善者 | `ESFJ.png` |
| 🔥 破壊者 | `ISTP.png` |
| 🩸 復讐者 | `ISFP.png` |
| 🐍 裏切り者 | `ESTP.png` |
| 🎪 混沌の道化師 | `ESFP.png` |

拡張子を変えたい場合は `data/types.ts` の各タイプの `image` フィールドを編集してください。
